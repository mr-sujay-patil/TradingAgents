# TradingAgents Web UI v2 Implementation Plan

**Spec:** `docs/superpowers/specs/2026-11-09-web-ui-v2-design.md`

Global constraints from the v1 plan still hold: no edits under `tradingagents/`
or `cli/`; Streamlit imported only in `app.py`, `pages/*`, `ui_common.py`,
`launch.py`; tests offline, tmp dirs only, pass under `TZ=America/New_York`;
`ruff check .` clean; no OpenAI calls.

### Task 1: Shared mechanics
- `events.py`: `RunEvent.kind` adds `"progress"`; fields `done`, `total`.
  `RunHandle(label, kind="analysis", request=None)`.
- `prefs.py`: `checkpoint: bool = True`.
- Tests: handle keeps kind/request; old prefs files load with `checkpoint=True`.

### Task 2: Portfolio store
- `webui/portfolio_store.py`: `PORTFOLIO_PATH`; `load() -> PortfolioContext | None`
  (missing/invalid → None); `save(ctx)`; `clear()`; `from_rows(rows, cash, currency)`
  (drops blank rows, raises `ValueError` with the pydantic message);
  `parse_upload(bytes) -> PortfolioContext`.
- Settings page: Portfolio section (data_editor, cash, currency, Save/Clear/Import).
- `RunRequest.portfolio: PortfolioContext | None = None`; runner passes it to
  `create_run_state` and the checkpoint calls.
- New run / Home: "Use my portfolio" checkbox when one is saved.
- Tests: round trip, blank rows dropped, bad quantity rejected, toggle off →
  `None` reaches the graph, toggle on → the book reaches it.

### Task 3: Checkpoint resume
- `RunRequest.checkpoint: bool = False`; `build_config` sets
  `checkpoint_enabled=req.checkpoint`.
- `start_run`: begin_checkpoint / inject thread id / checkpoint_input /
  clear_checkpoint_on_success / end_checkpoint in finally; emit
  `stage/resuming` when `graph._resuming`.
- Progress view: on error with `handle.request`, a Resume button →
  `start_run(handle.request)`.
- Tests: FakeGraph records calls; success clears; failure doesn't clear but ends;
  resuming emits the notice; Resume button restarts.

### Task 4: Outcomes
- `webui/outcomes.py`: `log_path()`; `Outcome` dataclass; `load_outcomes(path)`;
  `scores(path) -> BacktestSummary | None`; `outcome_index(path) -> dict[(ticker, date), str]`;
  `start_settle(req, graph_factory=None) -> RunHandle` (kind `settle`).
- `pages/outcomes.py`; History Outcome column; app navigation entry.
- Tests: parse a log written by `TradingMemoryLog` (pending + settled via
  `update_with_outcome`), empty/missing log, index, settle with a fake graph.

### Task 5: Backtest
- `webui/backtest_runner.py`: `MAX_CELLS = 60`; `BacktestRequest`;
  `plan_cells(req) -> (dates, cells, problem)`; `start_backtest(req, backtest=run_backtest)`
  (kind `backtest`, progress events, done carries summary text and run id);
  `past_sweeps(root) -> list[Sweep]`.
- `pages/backtest.py`; navigation entry.
- Tests: grid validation and cap, progress events, failures listed, past sweeps
  read from a tmp tree, page disabled in demo mode.

### Task 6: Verify and ship
- `pytest -q`, `TZ=America/New_York pytest -q`, `ruff check .`, bare install,
  all pages render in AppTest, server boots.
- README Web UI section + CHANGELOG.
